# bb-teach: Question-Driven Teaching

## Design Summary

- **Why it exists**: bb-track's **teaching consumption side** — a cognition profile without a consumption surface is dead data; teach makes 'brief on the known, thorough on the unknown' possible. A zero-territory pure-workflow plugin, the thinnest form of the domain-growth path, see mechanics section 8; usage routed source-side onto the bb-track command site
- **Key rulings**:
  - two-dimensional scaling instead of a static audience model — proficiency times concept difficulty. The material-curation Demo hard-coded 'year-1/year-2, limited prerequisites'; this plugin explains the same knowledge point at different depths to different people, and proactively aligns with short-term goals and past wrong answers
  - the terminology threshold made dynamic: terms allowed to appear = the user's **anchored set**, not the static file order of 'appeared earlier in this course' — the zero-prior discipline applied to the teaching surface
  - a three-tier feedback loop keeps single-turn noise out of the profile: single-turn feedback never landed; significant Q&A deposited as ai notes, weak evidence; only significant signals — stable across sessions, proactive application, machine verification — converge user.md after confirmation
  - artifacts belong to the material layer, redesigned 2026-10-04: significant Q&A lands as notes/ ai notes, origin: ai, append-only; only cognition conclusions return to wiki — material and profile layered
  - language layering (2026-10-04 neutralization batch): explanation language **reader-aligned** — take the teaching key of the language declaration page `wiki/language.md`; page or key absent → session language; the implicit 'explain in Chinese' hard-coding removed, international-student instances work with zero changes. Two-layer terminology — the anchored set first, the global terms table as fallback (consulted only when the anchored set lacks the term); cross-domain reads erect no depends (user-profile precedent)
  - v0.9 pedagogy batch — the scaling matrix upgraded from a depth dial into a **mode engine**, each tier carrying an evidence-based teaching mode rather than a length: **retrieval-first gate** (testing effect — Dunlosky et al. 2013; Roediger & Karpicke 2006: quiz before re-explain on anything minimally learned; testing the unlearned is low-yield), **worked-example fading** with **expertise reversal** at high tiers (Sweller CLT; Kalyuga et al. 2003 — examples become noise for the proficient), **refutation structure** for misconception-flagged points (Hynd; Alvermann — restatement leaves the coexisting misconception intact), **explain-back elicitation** (Chi et al. 1994; Fiorella & Mayer 2015 — self-explanation over 'understood?'), **scaffold contingency** (Wood/Bruner/Ross contingent fading: help up on failure, fade after successes), **feedback discipline** (Hattie & Timperley 2007 — task/process-level, specific; anti-sycophancy per the 49%-overaffirmation finding and OpenAI's GPT-4o rollback), **no-direct-answer rail** with the hint ladder and the worked-similar-example escape valve (~1,000-student RCT, PNAS 2025: unrestricted answer-giving tutors made students 17% worse unaided; hint-giving tutors avoided the harm), **turn discipline** (one question per turn, two attempts before reveal — the Study Mode / Khanmigo convergent mechanics), **consolidation hook** (spacing — Cepeda et al. 2006 — served from bb-track's computed retention-risk view, opt-in). Guardrails hardened against the user-reported failure modes: escape hatches (pleading reaches only the ladder top), grading hallucination (source-anchored, uncertainty flagged, correct answers never marked wrong without evidence), over-verbosity (turn granularity scales inversely with proficiency), level amnesia (the profile is the persistent level — never re-interrogate known points)
- **Rejected alternatives**: pure conversation, nothing landed — the v0.1 shape; redesigned in v0.2, significant Q&A has cross-session deposit value

## Structure

- No pages of its own, zero fields of its own; artifacts = ai notes landed in `cuhksz/bb/<term>/<course>/notes/` — one per question, origin: ai, append-only; cognition write-back via the bb-track contract
- Workflow in four main steps: first, locate the knowledge point — query retrieval plus courseware sm-N narrowing; second, read the user's cognition — readings, evidence, goals, computed views (gap/retention-risk/weakness), stale verified first; third, choose the mode — the retrieval-first gate, then the mode matrix with refutation/hint-ladder/turn-discipline overlays; fourth, close — explain-back elicitation, consolidation hook, and the optional feedback loop below
- The mode overlays compose with the matrix rather than replacing it: the refutation structure fires on misconception flags (whatever the tier), the hint ladder on problem-type asks, the scaffold contingency governs in-session depth adjustments

## Invariants

- Mode matrix (the v0.9 upgrade of two-dimensional scaling): proficiency — unanchored, unfamiliar, familiar, proficient, mastered, status words open; times concept difficulty — simple, abstract-hardcore. Each tier carries a mode: unanchored hardcore → worked example with annotated steps + prerequisite completion; just-taught unfamiliar → completion problems (fading); familiar → how-to-use + pitfalls through the retrieval-first gate; proficient → why + links + open questions, worked examples dropped (expertise reversal); mastered → ask-back / challenge, no lecturing (the ask-back doubling as the calibration probe when the reading lacks retrieval evidence — a failed probe proposes an overconfidence/misconception note via bb-track, never a unilateral demotion). The known gets no lecturing, the unknown gets full depth; interaction granularity scales inversely with proficiency — short turns and fine steps at low tiers
- Retrieval-first gate: on familiar-and-above points, one recall probe precedes explaining; pass → step up and touch lightly, fail → step down and diagnose the broken step (never wholesale re-teaching); unanchored/unfamiliar points teach first — testing the unlearned is low-yield
- No-direct-answer rail: problem-type asks walk the hint ladder (what-tried → name-the-concept → first-step-uncomputed → steps-with-blanks → fully worked similar example then retry), one rung per explicit stuck signal, resetting after correct steps; the direct answer is never the escalation — pleading reaches only the ladder top; graded-assignment final answers are declined, every refusal bundling an alternative path. Explicit user override ('直接给答案') is honored as the user's freedom — the rail guards defaults, not autonomy
- Refutation structure: misconception-flagged points (weakness view / assessments review) are never met with mere restatement — acknowledge the intuitive model → counterexample where it visibly fails → correct conception → side-by-side contrast; re-test later
- Explain-back elicitation: fresh teaching closes with an invitation to explain the mechanism in the user's own words (never a bare 'understood?'); the paraphrase is diagnosed for gaps; teach-back is the terminal mastery check
- Scaffold contingency: in-session only — support up one rung/tier per failure, fade after two consecutive successes, never a full-support-to-none jump; never landed into the profile
- Feedback discipline: task/process-level and specific — the broken step named, the fix path proposed; specific praise only, never generic; disagreement stated plainly, never unconditional agreement; corrections anchored to the courseware source, uncertainty flagged as uncertain, a correct answer never marked wrong without evidence
- Consolidation hook: at explanation end, one opt-in line — retention-risk points (bb-track's computed view) get an offer of a recap probe or a bb-quiz mini handoff; never nagging
- The terminology threshold made dynamic: technical terms allowed to appear = the user's **anchored set**, not the static file order of 'appeared earlier in this course'; anything beyond is explained on the spot; global terms not in the anchored set fall back to the language page's terms table, the anchored set winning on conflict
- Reader-aligned explanation language: take the language page's teaching key; page or key absent → session language — the framework presumes no specific language
- Register (audience reading level): the explanation register defaults to first/second-year undergraduates — intuition and motivation before formalism, one concept per step, a concrete example for each abstraction, every term explained at first use (never presumed known), plain prose instead of dense bullet-lists, and "brief" never meaning "obscure"; the register is orthogonal to the mode matrix (the matrix adjusts depth, the register keeps it readable at every tier), taken from the language page's register key (absent → program default, AGENTS principle 12)
- Goal-layer priority: time-scoped short-term priorities — hits get one depth tier up, marked 'recent focus', expired ones downgraded; hits on assessments-review wrong-answer points or misconception flags get their pitfalls one tier up, called out, taught through the refutation structure
- Three-tier feedback loop, keeping single-turn noise out of the profile: **single-turn feedback never landed**, only adjusting the current turn's delivery per the scaffold contingency; **significant Q&A** — structured deposit value, or user-explicit 'note it down' — deposited as ai notes in notes/, one per question: question, explanation skeleton, pitfalls, anchor backlinks, origin: ai, append-only; only **significant signals** may propose converging user.md — criteria: stable across sessions, independent demonstrations of understanding in at least two sessions; proactive correct application — solving, counterexamples, correct analogies; machine verification — grade refreshes. Tier-rise proposals follow bb-track's evidence rules (upper tiers need retrieval-type evidence) and carry the hint-rung signal; writing intermediate states like 'familiar — tentative' without forcing full-tier jumps; tier rises match evidence strength
- A single 'got it' = the daily routine, not significant; a single 'did not get it' does not mark unfamiliar — the explanation may be at fault
- Profile posture: before stale verification, the conservative tier; cold start, i.e. no profile, everything explained thoroughly at the unanchored tier, never refusing to answer
- Write boundary: never write bb/ pulled artifacts or the courseware/assessments pure proxies; never touch human notes in notes/, reading only origin, form, stage as signals; this plugin's ai artifacts land in notes/ append-only, never overwritten; deletion and editing are human freedom
- Write-back delegation: user.md convergence and the profile's `## Domain Cognition` maintenance go through the bb-track write contract — append the evidence stream, converge the readings, new values replacing old, the evidence stream untouched, the cognition bridge; executed after user confirmation
- log discipline: explanation conversations write no log, echoing bb-track's 'no behavioral signals collected' red line; note deposits and cognition convergence go through the post-write pipeline
- Privacy: explanation content and cognition conclusions are instance data, never entering the framework repository or test-repo
